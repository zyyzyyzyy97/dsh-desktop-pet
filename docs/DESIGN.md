## 0. 一条铁律，三层分工

**事实说"发生了什么"，心情说"我感觉如何"，她自己写的说"我是谁"。三者永远不混。**

| 层 | 变量 | 存储 | 谁有权写 | 注入形态 |
|---|---|---|---|---|
| 事实层（原有，微扩） | 句数/天数/记得的事/时间规律 | `memory.db` | 抽取器 + 代码 | relationHint 纯事实 |
| **心情层（本模块核心）** | mood(v,a)、baseline(v) | `runtime-data/inner.json` | **只有引擎**（模型只能提交冲量，引擎记账+钳制） | innerHint，人话+原因，平静时为空 |
| 人格层（自述式，扩容） | portrait 自画像 / moment 重要时刻 / diary / impression | `memory.db` blocks 表 | 她自己（反思任务） | diaryHint 三段式 + brief |

模型全程摸不到数字。亲密与性格变化走原路（事实 + 她自己写的东西），数值只管"此刻的心情"——
它应该像天气，不像剧本。

## 1. 心情引擎（`vendor/inner.ts`，新增 ~380 行）

### 1.1 状态

`runtime-data/inner.json`（原子写：tmp+rename；损坏自愈：重置中性+流水留痕）：

```json
{ "version": 1,
  "mood": { "v": 0.12, "a": 0.35 },      // 愉悦度[-1,1] 唤醒度[0,1]
  "baseline": { "v": 0 },                // 天级心境[-0.25,0.25]
  "lastTick": 0, "gapChargedUntil": 0,   // 衰减水位 / 冷落结算水位
  "lastEvent": { "dv": -0.1, "why": "被吐槽没良心", "ts": 0 },
  "lastSeenAt": 0,
  "proDate": "", "proToday": 0, "proLastAt": 0 }   // 主动陪聊计数
```

流水 `inner-log.jsonl`：每次冲量/衰减/冷落/过夜/重置一行（含原因），永不清理，黑匣子。

### 1.2 常量（全部集中在文件头，跑两周看流水再调）

| 常量 | 值 | 含义 |
|---|---|---|
| TAU_V | 3h | 愉悦度回归心境：被凶一句约半天缓过来 |
| TAU_A | 45min | 唤醒度静息：兴奋劲明显比心情短（A_REST=0.35） |
| TAU_B | 5d | 心境回中性：连冷落四五天她才会真蔫 |
| 冲量钳制 | 模型 ±0.3/±0.4，启发式 ±0.1/±0.15 | 不信模型自觉 |
| QUIET_V/A | 0.15 | 平静门槛：不够偏、又没新鲜事 → 一个字不注入 |
| GAP_TIERS | 6h/-0.1, 24h/-0.18, 72h/-0.25 | 冷落档位（一次性，过夜宽宥除外） |
| WHY_MIN_DV | 0.08 | 原因句门槛：3h 内 |dv| 达标才挂嘴边 |
| 软顶 | a/0.85 | 唤醒度越高正向 da 越推不动（防长聊爆表） |
| V_FLOOR | -0.85 | 赌气有底，绝不进负面螺旋 |

### 1.3 冲量三路

1. **模型标注**（主）：搭 EXTRACT 现车——EXTRACT_SYS v2 让同一次请求顺手输出
   `"mood":{"dv","da","why"}`，零新增请求。runLearn 解析兼容新旧两种输出格式。
2. **启发式**（辅）：长文 +0.1da；2h 后出现 +0.05dv；深夜(0-5点)**每次聊天开场只算一次**
   +0.05da/-0.03dv（防长夜聊把她越聊越蔫——仿真抓出来的）。
3. **间隔结算**：6h 起按档扣分，同一段缺席只扣一次（gapChargedUntil 水位）；
   ≥24h 归来 +0.1"他回来了"；**过夜宽宥**：19 点后走、6-11 点回、<18h = 睡了一觉，不算冷落。

事件合并规则：冷落 > 归来 > 启发式。原因句拣最重的说，数值各自叠加。
被动结算（hint/快照轮询）先撞上冷落线时，事件进 pendingGap 待领队列（60s 内有效），
touch 领回后才能把"冷落了多久，不过他回来了"接成一句话。

### 1.4 措辞生成（hint）

数值→词是"翻译"不是"分级"，相邻档共享用词防悬崖感；同档随机同义词防复读。
平静且无原因 → **空串**（沉默是默认态）。有原因但情绪没到说得出词的程度（30min 内）→
"现在的你说不上来是什么感觉（因为…）"——比沉默诚实，比硬编真实。
注入永远不带数字。

## 2. 人格层扩容

### 2.1 自画像 `kind='portrait'`（她是谁的长期沉淀）

挂 maybeReflect：每 12 句写完日记后检查——距上次 ≥12h **且** 新对话 ≥80 句 **且** 总量 ≥30 句
→ 整合任务：让她重读自己的日记/印象/旧画像，第一人称重写"我现在是谁"（≤200 字）。
不合格（<10 字 / >200 字）保留旧版，绝不空窗。旧版永远留在库里可回溯。
注入排在【你现在的样子】= 她自己写的三段之首——**身份先于近两天的心情**。

### 2.2 重要时刻 `kind='moment'`

整合任务顺带识别里程碑（第一次吵完架和好、他第一次说心里话、消失好几天后回来），
带具体细节，入库去重（标点归一化后互相包含即跳过），上限 8 条。
`brief()` 常驻【一直记得的时刻】最多 4 条——时刻的分量来自稀有。

### 2.3 时间感（relationHint 扩展，零新增存储）

从 turns 表现算：上次说话多久前（>30min 才说，正聊着不废话）、今天聊了几句、
近 7 天上线时段众数（样本 <5 或分布 <35% 不下结论——宁可不说，不说错）。
她由此自己长出"你去哪了""这个点还不睡"，不需要谁教。

## 3. 表达层

- **表情包偏置**（autoMeme）：正则命中多个时挑与心情同向的；全没命中但 |v|≥0.3 且隔两轮 →
  偶尔按心情补。频率闸（sinceLastMeme）不变——改的只是"选哪张"，不是"发不发"。
- **主动陪聊**（`cfg.proactive`，默认关）：挂 150s 间隔。全条件才掷骰子：
  页面在线 / 沉默 ∈[2h,8h] / 心情 > -0.35（气头上不找他——赌气要能持续）/
  今日 <2 次 / 安静时段(00:30-08:00)外 / **他没晾着上一次的主动**（proLastAt 之后他没来过话就绝不追问）/
  概率闸（平静 0.25、低落 0.08、很差 0）。
  发出的话照常进 memory 和 history——她记得自己开过这个头。
  测试旋钮：PRO_FORCE / PRO_SILENCE_MIN / PRO_SILENCE_MAX / PRO_INTERVAL。

## 4. system 注入布局（askModel）

```
1. persona（反人设底座 + 新增一句：心情和样子也是你自己的东西）
2. VISION_HINT（有图时）
3. relationHint()      ← 真实底子 + 时间感事实
4. innerHint()         ← 【你此刻的心情】平静时是空串
5. diaryHint() 三段式  ← 【你现在的样子】portrait
                         【你对他攒下的印象】impressions
                         【你自己写过的日记】diaries
6. brief()             ← 【你记得的事】【一直记得的时刻】【更早以前的印象】【他以前说过的事】
7. memeMenu / QQ_HINT
```

## 5. 明确不做的（守住 17:50 修正的成果）

- 不往 relationHint 加 trust/closeness 数值——那等于把阶段曲线换个数字还魂
- 不做任何"X 句解锁 Y"的闸门
- 不让 LLM 直接写 inner.json 的数字
- mood 不调制 temperature/maxTokens/音色——一个变量一条通道，出问题好归因
- 不做 baseline 的模型直写——它只能被反思任务以 ±0.02 的小步推动（v2 预留，暂未实现）
